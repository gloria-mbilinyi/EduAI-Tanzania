# EduAI Tanzania Ltd

AI-Powered Learning and School Management Platform for Tanzanian Secondary Schools

A bilingual secondary-school learning and management prototype. React and
FastAPI provide role-specific workflows over a normalized relational database.
All sample people and schools are fictional. AI uses transparent rules and
curriculum retrieval; payments use an explicitly simulated provider.

Implementation, test evidence, diagrams and installation instructions are
maintained in this repository. The project is an academic prototype, not a
production service or a validated predictor of student outcomes.

The original GitHub README commit is preserved in the integration merge.
